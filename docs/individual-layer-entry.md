# Individual layers and the full PBS stack

Founder direction010 clarifies optional entry within existing V1 objectives01/02/03/08. Same BOAS root/version; billing excluded.

The existing consultation.html accepts ?use=pqs, ?use=pbrs, ?use=pbb, ?use=pseq or ?use=all. The choice can also be changed without leaving the page. PQS and PBRS show their respective review directly. PBB opens the known-problem plan builder/import. PSEQ opens registered work plus optional existing-plan import or direct task-scope setup, reusing the working-plan capability without requiring an earlier-layer purchase. Entire stack keeps the connected workspace.

One account/business owns all saved history. View switching does not clear drafts, create records, establish entitlement, infer payment, award task credit or verify readiness. Recovery lists focus on the selected layer; signing out still clears private state. Printing excludes panels outside the selected view. Invalid view parameters fall back to the whole stack. Pending assessment saves prevent switching the review depth until resolved.

No final offers, module prices, payment-derived entitlements or public release are established. This is construction source on existing draft PR2. A future separately governed billing service may enforce approved purchases; choosing a view cannot grant that authority.

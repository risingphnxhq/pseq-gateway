# PBS continuing consultation — construction status

PBS starts with the business's current model, decision, goal, stage and resources. It retains questions, selected evidence, work drafts, context revisions and prior guidance. Existing businesses do not need to repeat a beginner diagnostic.

The dedicated consultation service is deployed with authenticated customer ownership checks and explicit customer consent. GPT-6.1 Sol provider access has been demonstrated. Outbound context is selected business context, evidence descriptions, selected work and the latest four bounded history summaries. Raw authentication/business/case identifiers are excluded from model context. Known sensitive patterns are rejected, but this is not a guarantee of complete de-identification. Do not submit credentials, account numbers, personal customer records or confidential third-party documents.

The service uses structured responses, store=false, no action tools, at most 3500 output tokens and a 90-second provider timeout. Limits remain 20 model attempts globally and five per customer per Chicago day; failed attempts count. These are request caps, not dollar caps. Retries replay recorded state without automatically repeating provider processing. Incomplete, rejected and uncertain responses are explicit, with no canned replacement labeled as AI consultation.

The response contract covers evidence-linked hypotheses, decision-changing followups, alternatives, resource fit, useful work products, criteria feedback and adaptation. Submission, work quality and observed business outcomes remain distinct. Funding is a milestone in continuing consultation, not its terminal goal or a requirement to borrow again.

## Submission review

The construction interface connects the latest saved submission to the existing business case. It recovers and displays the stored note and agreed task criteria before a separate processing acknowledgment. The customer cannot replace the bound work with different text in the review request. Referenced attachments are not retrieved or independently verified.

Server reservation snapshots the selected submission's note/title/criteria. Quality publication is a separate disabled-by-default gate. When accepted for activation, only the dedicated service may publish a criteria assessment against the reserved latest submission. A newer correction supersedes a pending older review. Duplicate results cannot create duplicate credit. Deficient work retains its receipt and requires correction under the same task. Clarification does not silently accept work. No criteria assessment verifies actual business results, professional compliance or funding eligibility.
